# Job Portal User Application

A complete job seeking platform featuring AI-driven resume analysis and streamlined job application processes.

## Features
- AI Resume Analysis: Integrated with Google Gemini AI API to provide intelligent feedback on user resumes.
- Job Search and Filtering: Advanced system for users to find relevant job opportunities.
- Application Tracking: Real-time status updates for submitted job applications.

## Technical Stack
- Backend: Laravel 11
- Frontend: Tailwind CSS and Blade Templates
- AI Integration: Google Gemini AI API
- Database: MariaDB
